# Scripts

Python helpers for repeatable benchmark capture and regression checks:

- `collector_codec_bench.py` — compare collector output codecs.
- `perf_capture_baseline.py` / `perf_regression_check.py` — engine and parser baselines.
- `ws_ingest_capture_baseline.py` / `ws_ingest_regression_check.py` — WebSocket ingest baselines.

Run them from the repository root with Python 3.
